# Database Schema

14 tables. All extend `BaseEntity`: `id` (bigint identity), `created_at`, `updated_at`
(`timestamptz`, JPA auditing via `@EnableJpaAuditing` in `config/JpaAuditingConfig`).

## Type mapping

| Java | PostgreSQL |
|---|---|
| `Long` id | `bigint generated by default as identity` |
| `Instant` | `timestamptz` |
| `BigDecimal` money | `numeric(10,2)` |
| enums (`EnumType.STRING`) | `varchar(30)` |
| `UUID` | `uuid` |
| long text | `text` |

## Enums (`entity/enums/`)

- `Role`: ADMIN, INSTRUCTOR, STUDENT
- `CourseLevel`: BEGINNER, INTERMEDIATE, ADVANCED
- `CourseStatus`: DRAFT, PUBLISHED, ARCHIVED
- `LessonType`: VIDEO, TEXT, FILE
- `EnrollmentStatus`: ACTIVE, COMPLETED, CANCELLED
- `QuestionType`: SINGLE_CHOICE, MULTIPLE_CHOICE, TRUE_FALSE

## Tables

**users** — `keycloak_id uuid not null unique` (JWT `sub`), `role` not null (synced from
Keycloak), `full_name varchar(120)` not null, `email varchar(255)` not null unique,
`avatar_url varchar(500)`, `bio text`, `active boolean default true`. Index on `role`.
No password column. No refresh-token table.

**categories** — `name varchar(100)` unique, `slug varchar(120)` unique, `description text`.
Course count is computed (published courses only), never stored.

**courses** — `instructor_id → users`, `category_id → categories (RESTRICT)`,
`title varchar(200)`, `slug varchar(220)` unique, `description text`, `level`,
`price numeric(10,2) CHECK >= 0`, `thumbnail_url`, `status default DRAFT`,
`avg_rating numeric(3,2) default 0`, `review_count int default 0`,
`enrollment_count int default 0` (cached), `published_at`, `archived_at`.
Indexes: category_id, instructor_id, level, price, status, published_at, and GIN full-text on
`to_tsvector('english', coalesce(title,'') || ' ' || coalesce(description,''))`.
Methods: `publish()`, `archive()`.

**sections** — `course_id → courses (CASCADE)`, `title`, `sort_order int`.
`UNIQUE (course_id, sort_order) DEFERRABLE INITIALLY DEFERRED`.

**lessons** — `section_id → sections (CASCADE)`, `title`, `type`, `video_url`,
`duration_seconds` (VIDEO), `body text` (TEXT), `file_url` (FILE), `sort_order`,
`preview boolean default false`. `UNIQUE (section_id, sort_order) DEFERRABLE INITIALLY DEFERRED`.

**lesson_resources** — `lesson_id → lessons (CASCADE)`, `title`, `file_url`, `mime_type`,
`size_bytes bigint`.

**enrollments** — `student_id → users`, `course_id → courses`, `price_paid numeric(10,2)`
(price snapshot; source of revenue), `status default ACTIVE`, `progress_pct numeric(5,2) default 0`,
`enrolled_at`, `completed_at`. `UNIQUE (student_id, course_id)`; index
`(course_id, enrolled_at)`. Method `markCompleted()`.

**lesson_progress** — `enrollment_id → enrollments (CASCADE)`, `lesson_id → lessons (CASCADE)`,
`completed boolean`, `completed_at`. `UNIQUE (enrollment_id, lesson_id)`.

**quizzes** — `lesson_id` nullable, `section_id` nullable (both CASCADE), `title`,
`pass_mark int CHECK 0–100`, `time_limit_minutes` nullable.
`CHECK ((lesson_id IS NULL) <> (section_id IS NULL))`, also validated in `@PrePersist/@PreUpdate`.

**quiz_questions** — `quiz_id (CASCADE)`, `question_text text`, `type`, `points default 1`,
`sort_order`.

**quiz_options** — `question_id (CASCADE)`, `option_text varchar(500)`, `correct boolean`.

**quiz_attempts** — `quiz_id`, `student_id → users`, `score numeric(5,2)`, `passed`,
`started_at` not null, `submitted_at`. Index `(quiz_id, student_id)`.

**attempt_answers** — `attempt_id (CASCADE)`, `question_id`, `option_id` nullable.

**reviews** — `course_id`, `student_id`, `rating smallint CHECK 1–5`, `comment text`.
`UNIQUE (course_id, student_id)`.

## Relationship rules

- Compositions use `cascade = ALL, orphanRemoval = true` and `ON DELETE CASCADE`:
  Course→Section→Lesson→LessonResource, Quiz→QuizQuestion→QuizOption,
  QuizAttempt→AttemptAnswer, Enrollment→LessonProgress.
- Everything referencing `users`, and `courses.category_id`, uses `RESTRICT`.
- No `@OneToMany` collections on `User`.
- Ordered children use `@OrderBy("sortOrder ASC")`; parents have `addX/removeX` helpers.

## Flyway

- `V1__init_schema.sql`: tables in dependency order, all FKs, UNIQUEs, CHECKs, indexes —
  matching entities exactly so `ddl-auto=validate` passes.
- `V2__seed_data.sql`: categories Programming, Design, Business. No users (they come from
  Keycloak).
- Later changes: new `V3__...sql` files. Never edit an applied migration.
- If Flyway complains about a non-empty schema (tables made earlier by `ddl-auto=update`),
  drop and recreate `elearning_db` in development.

## Reorder technique

Because of the `(parent, sort_order)` unique constraint, reorder in one transaction: shift all
sort orders negative, flush, then assign 1..n. The deferrable constraint makes this safe.
